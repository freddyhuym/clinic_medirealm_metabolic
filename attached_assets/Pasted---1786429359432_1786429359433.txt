【五、非常重要：兩台儀器圖片大小】
────────────────────

我提供的兩張原圖本身比例不同：

Oligio X 為黑色機身，
圖片較偏橫向／留白比例不同。

Tightan 為白色機身，
圖片較高、較窄。

請「不要修改圖片本身」來硬湊比例。

正確做法是：

建立一個完全相同尺寸的圖片容器。

例如概念：

.device-image-wrapper {
    width: 100%;
    height: 420px;
    display: flex;
    align-items: center;
    justify-content: center;
}

.device-image-wrapper img {
    width: 100%;
    height: 100%;
    object-fit: contain;
}

實際高度請依照目前網站版面調整，
不要一定照 420px。

重點是：

兩張卡片的圖片顯示區尺寸必須完全一致。

圖片使用：

object-fit: contain;

不要使用：

object-fit: cover;

因為不能裁切機器。

【六、儀器本體的視覺比例】
────────────────────

除了圖片容器一樣之外，
請進一步讓兩台儀器在畫面中的「視覺高度接近」。

因為兩張原圖本身周圍留白可能不同，
請使用 CSS：

max-width
max-height
padding
transform scale（僅必要時）

等「顯示層級」方式調整。

注意：

可以調整整張圖片的顯示尺寸，
但不能對機器本體做局部變形。

禁止：

width 與 height 不同比例縮放

禁止把機器拉寬。

禁止把機器壓扁。

必須保持：

height: auto;
aspect-ratio: auto;

也就是保持原始圖片比例。

最終希望使用者看到：

Oligio X 和 Tightan 在兩張卡片裡的機身高度大約落在相同視覺範圍，

而不是一台非常大、一台非常小。
